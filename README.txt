# AutoNovaX Portal
Web estática inicial para un portal profesional de vehículos.

Incluye:
- buscador y filtros
- ordenación
- tarjetas de vehículos
- favoritos con localStorage
- ficha individual
- galería
- equipamiento y datos técnicos
- contacto y WhatsApp
- diseño responsive

IMPORTANTE: es una versión frontend. Para cuentas reales, base de datos, panel de administración multiusuario, mensajes persistentes, financiación, etc., hace falta backend/servicios externos.
